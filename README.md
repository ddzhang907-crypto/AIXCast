# AIXCast

用 AI 开发的跨设备投屏应用，目前提供 Android 接收端、Android 发送端和 Windows 发送端体验版。

当前发布目录：[XCast-体验版-20261113-125217](./XCast-体验版-20261113-125217/)。请完整下载或复制该目录，内含 Release 版本应用、必要运行文件及一份简短使用说明。

本次更新标准版和系统版 Android 接收端，Android、Windows 发送端沿用上一版。接收端主要更新：

- 修复 AirPlay 设备发现问题，调整首页布局。
- 投屏菜单按钮单排展示；音画同步与低延时使用统一按钮样式，点击后切换图标和文字。
- 观看时按返回键弹出断开投屏确认框；选中一路后，确定键和菜单键均可打开该路控制菜单。
- 从按钮按上键进入 DLNA 视频进度条后，按下键返回原按钮。

| 版本 | 当前情况 | 使用要求 |
| --- | --- | --- |
| Android 接收端标准版 | 已提供，支持 DLNA、AirPlay、XCast 和网页投屏 | Android 7.0 及以上，普通 Android 设备优先使用此版 |
| Android 接收端系统版 | 已提供，在标准版基础上增加 Miracast | **需要安装在使用 KK（康佳）签名、且与本 APK 系统签名匹配的电视上**；Miracast 还需要电视固件支持 Wi-Fi Direct |
| Android 发送端 | 已提供，支持屏幕镜像及视频、音乐、照片投屏 | Android 10 及以上；屏幕镜像需确认系统共享授权 |
| Windows 发送端 | 已提供，支持屏幕镜像、系统声音及视频、图片投屏 | Windows x64；保留完整目录即可启动，无需额外安装运行库 |
| Linux 发送端 | 已在 Ubuntu x64 虚拟机环境开发，**暂未打包** | 当前发布目录不包含 Linux 版本 |
| 苹果发送端 | **暂无苹果设备，尚未开发专用发送端** | 当前发布目录不包含 iOS / macOS 客户端 |

Android接收端-标准版/

使用步骤：

1. 完整下载或复制发布目录，让接收设备和发送设备接入同一局域网。
2. 在电视或 Android 设备上安装并打开接收端。普通设备选择标准版；符合 KK 签名要求的电视可选择系统版，两种接收端选一种使用。
3. Android 发送设备安装发送端 APK；Windows 电脑双击 `Windows发送端/XCastSender.exe`。选择接收设备和投屏内容，再按界面提示开始投屏。
4. 网页投屏可在电脑浏览器打开 [sxcast.top](https://sxcast.top)，输入接收端显示的投屏码，再选择共享内容。网页配对需要联网，音视频在局域网内传输。

请保留 Windows 程序旁的 DLL 和其他随附文件。屏幕镜像需要正常的显卡驱动和 H.264 硬件编码能力；防火墙提示时允许访问当前局域网。

两版接收端已完成编译、签名与文件完整性检查。Windows 发送端沿用此前已验证可从独立目录启动的版本。不同设备的实际投屏兼容性、声音和流畅度仍需实际体验，尚未覆盖所有机型和系统。
